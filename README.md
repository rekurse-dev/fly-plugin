# Fly Plugin
Simple, yet powerful.

## Features
* Fly command (/fly)

## Permissions
Requires you to grant `flyplugin.fly` to a specified player.

## Supported Versions
* **Supported Versions:** 1.21-26.3
* **Tested Versions:** 1.21.11, 26.2, 26.3
* *Note: This plugin may work on older versions, but it has not been officially tested on them.*

## How To Install
1. Download the latest .jar file through Modrinth or GitHub
2. Drop the jar into the `plugins` folder (located on the root of the server)
3. Grant a specified player the required permission `flyplugin.fly`
4. Run `/fly`

## Compiling from source

1. Clone the repository from GitHub
2. Navigate to the project directory
3. Run the build command (`./mvnw package`, or `mvnw.cmd package` on Windows)
4. The compiled .jar file will be located in the `target` folder
5. Drop the jar into the `plugins` folder (located on the root of the server)
