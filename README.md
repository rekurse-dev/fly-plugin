# Fly Plugin
Simple, yet powerful.

## Features
* Fly command (/fly)

## Permissions
Requires you to grant `flyplugin.fly` to a specified player.

## How to install
1. Download the latest .jar file through Modrinth or GitHub
2. Drop the jar into the `plugins` folder (located on the root of the server)
3. Give a specified player permission `flyplugin.fly`
4. Run /fly
